# Static FIRI corridor contract

Planner 3 uses one ConvexCorridor generator with whole-cell grid input, normalized halfspaces and arbitrary polygon vertices. Do not restore rectangle width scanning or interpret occupied centers as zero-size obstacles.

- Whole-cell exclusion requires one separating plane whose obstacle-side support includes every vertex of that convex cell.
- Preserve selected backend semantics: global ESDF then static PCD via isStaticTraversable, otherwise local isTraversable. Do not add observed-FREE requirements, alter unknown policy or silently switch sources. Static known masks are inferred-model support, not observed-free proof. All current queries are floor-indexed XY bins; whole rejected bins are obstacles. Review this abstraction if interpolation is introduced. Out-of-domain remains excluded.
- Preserve continuous original A* edges. Generate endpoint-protected segments, then prune backwards using earliest certified predecessors. A skipped span needs analytic halfspace clipping/interval-union coverage of every original edge and the existing positive-interior overlap witness. Final full-path coverage and all joins are rechecked within the global deadline. s0/s1 remain original seed metadata, not coverage certificates. No shortcut across uncovered path intervals; raw-generation region caps still apply.
- Rebase optimization/intersections and compute area after subtracting a vertex. Absolute-coordinate shoelace can falsely pass an impossible overlap threshold at large offsets.
- Reject unsupported numerical scales; see ConvexCorridor::buildStatic. Geometric separation has no solver status. MVIE max-evaluation/time and other solver failures reject; only its existing ROUNDOFF_LIMITED exception may provide a candidate to the unchanged finite, positive-diagonal, containment and shrink certificates, never advertise solver success. Clear partial output on any failed certificate.
- Geometric overlap is not a footprint/LFPC/dynamic guarantee. Iterative volume-seeking inflation is not global polygon-volume optimization.
- Preserve foot/CoM static collision, union hard check, final weighted rollout and STOP. Test these through the production MpcController path, not just geometry fixtures.
- Preserve pinned MIT provenance in path_searching/FIRI_NOTICE. C++ uses finite angular geometric separation and existing NLopt SLSQP with analytic gradients only for MVIE; it is an adapted whole-cell 2D formulation, not unchanged upstream 3D point-obstacle FIRI.

Required regressions include dense-vs-sparse straight paths, corners/S, cell-edge crossings, unknown/map edge, insufficient overlap, invalid/no-progress/budgets, solver failure, translated valid geometry, unattainable overlap threshold and rejected unsupported scales. Build plan_manage as well as the geometry library after interface changes.

## Approved original-edge segment revision (2026-09-07)

The runtime now walks original A* edges without shortcuts, subdividing at a configurable maximum segment length (default 1 m). Each restrictive solve protects both endpoints with the metric clearance norm included in its constraints; final normalized planes certify both endpoints and whole blocked cells. MVIE-only certified roundoff handling is unchanged.

The old min_progress, overlap_depth and overlap_area configuration is removed. Adjacent regions require a local-frame witness with at least 1e-6 m slack (100 times the 1e-8 m vertex feasibility tolerance), rather than a physical-sized disk or fixed area. A failed direct overlap inserts the same FIRI at the shared endpoint and checks both joins; failure clears all output. Connection regions count toward the global region/time budget. No footprint or LFPC guarantee follows.

Snapshot v2 stores max_segment_length. v1 readers explicitly consume and discard historical geometric-only progress/depth/area fields; the new segment length defaults to 1 m, never reinterpreting area as length. Historical failure diagnostics remain intact.

All three exact historical fixtures require and achieve feasibility, each with 81 original edges and 81 regions. The historical closest-pair SLSQP initialization is superseded by the finite angular separator below; it is not a runtime contract. Diagnostics now include endpoint constraint violations. ## Corridor-bound A* edges
Planner 3 passes the resolved corridor clearance to A*. Candidate and terminal edges must exclude entire blocked native bins using the existing selected-backend adapter (global ESDF, static PCD, local SDF precedence), exact closed segment/cell intersection and metric distance. No sparse samples or endpoint-only fallback on unavailable data. Boundary enumeration guards must not relax collision distances. Other planners retain their existing margins. Edge validity does not guarantee FIRI numerical success.

Planner-3 soft preference uses `length + w_clearance * integral(max(0, 1 - max(0,d-clearance)/clearance_sigma)^2 ds)`, where d is distance to those SAME whole blocked bins or finite-domain exterior, not raw ESDF. Reuse bounded per-edge adapter crops; no second classifier, safety radius, or whole-map extraction per candidate. Midpoint quadrature spans every edge including the exact goal connector, with step <= min(0.02 m, native_resolution/2, sigma/16); only this comfort integral is approximate, never the hard certificate. Sigma is a preferred additional-clearance range, finite [0.01,5] m; weight is finite and nonnegative. With nonzero weight, search also preflights the selected native resolution and maximum aligned query: `bins=ceil((1.5*search_resolution+2*(sigma+clearance+1e-9))/native_resolution)+1`. Require bins<=1000 and bins*native_resolution<=100 m; otherwise reject before expansion with `UNSUPPORTED_PREFERENCE_GRID`, not a misleading no-path/INF result. This conservative uncropped bound includes off-lattice terminal connectors; small cropped maps do not exempt an unsupported parameter combination. There is no zero-penalty fallback. Planner-3 launch defaults are weight 1, sigma 0.8 m, lambda 1; this initial preference is not a footprint guarantee and must not close narrow passages. Other planner defaults remain weight 0 and lambda 0.2. Omitted `setParam` sigma retains the legacy 0.5 m fallback; planner-3 launches explicitly supply 0.8 m.

Corridor-bound search uses a start-anchored integer lattice and physical metre costs, immutable priority entries with stale-entry removal/reopening, and uninflated Euclidean lambda-scaled heuristic. The exact terminal connector competes as a costed virtual goal, not an uncosted early return. At search-horizon termination, return the best already certified complete goal candidate if one exists instead of discarding it for a partial path; otherwise preserve partial-horizon behavior. This horizon result is not an optimality certificate. A* has no wall-clock deadline: the manager's 100 ms FSM period and FIRI's separate 0.5 s cooperative deadline do not bound A*. Lambda >1 is weighted search, not optimal A*. Numerical quadrature, finite search bounds/horizon and node budget preclude a continuous/global optimality claim. Regressions compare against lambda=0, fine quadrature, native/search grid refinement and all three selected backends. No smoothing, duplicated waypoints, runtime replan recovery or map-fluctuation fix belongs to this preference.

## Finite angular restrictive separation

The earlier edge72 SLSQP initialization/tolerance fix is superseded: no separator initial guess, optimizer tolerance, success-status requirement or alternate-solver prohibition remains. One finite geometric implementation enumerates stationary, cell-support-switch and endpoint-clearance-active directions. For unit normal u the objective is the **unshifted signed support ratio** min_v u.(v-center)/|L^T u|, subject to u.(v-seed_i)>=clearance for every cell vertex and both endpoints. It is NOT maximization of the clearance-shifted radius (min_v u.(v-center)-clearance)/|L^T u|. The plane offset is min_v u.v-clearance and may have either sign relative to the moving ellipse center.

Empty feasible candidates reject as REFERENCE_OCCUPIED; nonfinite calculations and expired deadlines reject explicitly. Independent normalized metric endpoint and whole-cell certificates remain unchanged. The MVIE-only certified roundoff exception above is unchanged; no separation roundoff acceptance, retry, angular sampling, cell-center approximation or certificate relaxation is introduced. Historical snapshot solver diagnostics remain readable. Test both feasibility and the unshifted objective, including stationary, support-switch, clearance-active and center-at-cell-vertex cases. The frozen M6wfx3 same-map sweep requires all 14 independently valid cases to succeed and all 3 obstructed cases to reject; the old illegal A* diagonal still rejects. Full catkin integration/navigation remain untested.
